核心特性

订阅 → 解析 → 入库 → 信息流 → 详情阅读，一个完整的最小闭环。

订阅最小闭环

添加订阅源 → 解析 → 入库 → 信息流浏览。常规 RSS / Atom 与 RSSHub 路由同等支持。

RSSHub 路由目录

添加订阅抽屉内置全量路由目录，关键词搜索、分类浏览、热度排序；点选路由填参数即可订阅。

摘要与正文分离

feed 自带全文优先，缺失时在打开文章时按需抓取原网页正文（带文件缓存，失败静默回退摘要）。

AI 摘要 · 翻译

详情页常驻摘要卡片，一键生成全文概括；外文文章一键整体译为简体中文（替换式显示，随时切回原文）。

阅读排版

详情页内调整字号、行距、左右边距、字体族，即改即见、全局记忆。原生渲染器为主，必要时回退 WebView。

分页 + 并行刷新

所有列表分页加载（每页 30 条），全量刷新多路并行（并发上限 8），适配上千订阅源、数万篇文章。

深色模式

浅色 / 深色 / 跟随系统三档，阅读页同步适配。

OPML 导入导出

标准 OPML 订阅清单，文件夹结构还原为分组；导入「盲导」不联网逐个校验。

站点图标

自动抓取源站点图标，仅首次获取、写入后不覆盖，加载失败回落字母占位。

RSSHub 路由目录

应用随包内置精简快照（基于 官方路由元数据），保证首次安装离线可用；联网可更新。

# 知乎热榜（无需参数）

# B 站用户投稿
https://<instance>/bilibili/user/video/:uid

# 微博热搜
https://<instance>/weibo/search/hot

快速开始

当前尚未发布签名 APK；推荐从源码构建调试包。所有数据仅存本机，无需注册。

1. 克隆与构建

git clone https://github.com/mariamjensen42-glitch/RssRadar.git
cd RssRadar
./gradlew assembleDebug

2. 安装到设备

构建产物位于 app/build/outputs/apk/debug/app-debug.apk。Android 12+ 设备允许安装未知来源后直接安装。

3. 添加第一个订阅

底部抽屉点 FAB → 添加订阅，进入内置路由目录；搜索「知乎热榜」或按分类浏览，点选路由 → 订阅。

4. 可选：启用 AI 摘要 / 翻译

「我的」页填入你自己的 DeepSeek API Key（仅存本机，不上传）。详情页点摘要卡片生成 AI 摘要，外文文章点翻译按钮一键转中文。

常见问题

为什么是 RSSHub 而不是直接订阅原始 RSS？

很多站点只提供网页、不提供 RSS；RSSHub 把这类站点统一成 feed。RssRadar 把 RSSHub 路由目录内置进 App，填参数即订阅。当然常规 RSS / Atom 链接同样支持。

数据放在哪里？

全部本机（Room 数据库 + 文件缓存）。无账号、无后端、无遥测。

AI 摘要 / 翻译的数据会外发吗？

只在用户主动点生成/翻译时，把当时阅读的文章正文发到 DeepSeek 用于推理；API Key 仅存本机 SharedPreferences，不上传任何服务器。

RSSHub 实例为什么有时快有时慢？

公共实例漂移严重（实测不到两小时排序全变），App 在每次刷新前按当次探活耗时取最快者，并允许用户在设置页切换 / 添加自定义实例。

能不能从其他阅读器迁移订阅？

支持标准 OPML 导入导出：「我的 → OPML 导入」。文件夹结构会还原为分组，文章由导入后的刷新补齐。
