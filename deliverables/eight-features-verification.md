# 八项新功能 · 真机验收清单

> 本机不能跑 gradle（工程约定），所以 KSP 产物、Room 升级校验、音频服务这些**只能靠真机确认**。
> 下面每一项都给了入口路径与判定标准。构建方式：Android Studio 跑 `app`。

```bash
# 先确认静态检查与单测是绿的（本机可跑）
python scripts/check-kotlin.py            # 期望：0 error

python scripts/check-room-schema.py       # 期望：只剩 6 处「多余」——那是 build 里的旧 KSP 产物
```

真机构建会重新生成 KSP 产物，`check-room-schema.py` 应回到 0 差异。

## ① 升级路径（**最高优先级**）

装旧版本（v16 数据库）→ 覆盖安装新版。

- 期望：能正常启动，不闪退。
- 崩了就是 `MIGRATION_16_17` 与 Room 期望不一致（本机已逐项比对实体列与迁移 SQL，但 `onValidateSchema` 只能在真机跑）。
- 验证点：升级后打开一篇文章，收藏它 → 收藏页「按收藏时间」排序应把它排在最前（`starredAt` 回填生效）。

## ② 完整数据备份 / 恢复

入口：我的 → 备份与恢复

- 导出：可勾选「包含文章正文」；导出成功后有文件大小提示。
- 导入：合并 / 覆盖两种策略；覆盖会二次确认。
- **必须验证**：备份文件里**不含 API Key**（用文本编辑器搜 `sk-` 应无命中）。
- 验证点：导出 → 清库或换机 → 导入 → 订阅、文章、已读/收藏/稍后读状态、AI 产物都在。

## ③ 关键词过滤规则

入口：我的 → 关键词过滤

- 新建一条「标题包含 XXX → 隐藏」→ 保存。
- 期望：提示「规则已保存，全库重扫后共影响 N 篇」；回信息流确认那些文章真的没了。
- 收藏或稍后读的文章**不应**被删掉（豁免）。
- 新文章侧：等一轮自动同步后，新命中的文章不该出现。
- **边界确认**：规则删掉后**已删的文章不会回来**（不可逆，这是设计）。

## ④ 搜索（FTS + 二次筛选）

入口：底部搜索 tab

- 纯中文词（如 `人工智能`）能搜到；单字（如 `猫`）也能搜到（走 LIKE 回退）。
- 结果数显示的是**总命中数**，滚动加载更多时数字不变。
- 切换时间范围 / 未读 / 收藏 / 稍后读 / 来源，结果立即重算。
- 「清除筛选」把条件归零。
- **边界**：老库需要索引补齐，冷启动会排一个后台任务；若升级后立刻搜不到旧文章，等几分钟或到「备份与恢复 → 重建索引」手动跑一次。

## ⑤ 页码内查找

入口：阅读页 → 右上角 ⋯ → 在页面中查找

- 原生渲染（设置里把渲染器切成「原生」）：输入词 → 命中高亮蓝色、当前命中橙色；上一处/下一处会把视口滚过去。
- WebView 渲染且正文**有图**（视口模式）：命中高亮，上下处能滚。
- WebView 渲染且正文**无图**（整页模式）：会显示「无法自动滚到位置上」——这是平台限制，如实标注而非静默失效。
- 译文视图下打开：显示「译文视图下暂不支持页内查找」。

## ⑥ 高亮标注 / 笔记

入口：阅读页正文长按选中文字

- 选中后底部浮出工具条（5 个色点 + 记笔记 + 复制 + 收起）。
- 点色点 → 该处立即出现对应底色高亮。
- 记笔记 → 填内容 → 保存 → 高亮仍在，笔记进列表。
- 复制 → 系统提示已复制。
- 跨段落选择：每段各生成一条标注（预期行为）。
- 全局列表：阅读页 ⋯ → 我的标注，或 我的 → 我的标注。点一条回到原文，垃圾桶删除（二次确认）。

## ⑦ 音频 / 播客播放

入口：**有音频地址的**文章 → 底部操作栏耳机图标

- 有音频地址才会有这个按钮；没有就不显示（不留死按钮）。
- 播放页：封面、进度条（可拖动）、±15 秒、上一集/下一集、倍速。
- **锁屏/切后台继续播**；通知栏有播放控制。
- 拔耳机自动暂停。
- 队列是同一订阅源的音频，按时间新→旧。
- 若某篇显示「这篇没有可播放的音频地址」：说明该源只给了 MIME 类型没给 URL，属于数据问题不是 bug。

## ⑧ 收藏再组织

入口：我的 → 收藏与稍后读

- 顶部切换收藏 / 稍后读。
- 排序（收藏时间 / 发布时间 / 来源）、时间范围、来源筛选都可切换。
- **长按**任一条进选择态 → 勾选多条 → 「取消收藏」批量移出。
- 触底自动加载更多。
- 偏好会记住（下次进来还是上次的排序与筛选）。

## ⑨ 通知细粒度

入口：我的 → 同步与清理 → 新文章通知

- 勿扰时段：设一个**跨天**的区间（如 23:00–07:00）→ 时段内不发通知。
- 关键词：包含 / 排除，保存后按规则过滤通知内容。
- 与过滤规则的「不发通知」动作叠加生效。

## 已知边界（不是 bug，是明确取舍）

| 项 | 边界 | 原因 |
|---|---|---|
| 页内查找 | 整页 WebView 不自动滚动 | 正文由外层 Compose 滚，WebView 自己滚不动 |
| 页内查找 | 译文视图不支持 | 分段重排后文本与原文对不上 |
| 高亮 | WebView 渲染的正文不支持划词高亮 | 标注渲染挂在内置渲染器上；WebView 路的降级就是「不显示高亮」，不影响已有标注 |
| 过滤规则 | 删除规则不复活已删文章 | 归档不可逆，与「文章清理」同语义 |
| 过滤规则 | 保存时全库重扫，数万篇时可能卡几秒 | 无进度条，读完提示即完成 |
| 音频 | 列表卡片无媒体角标 | 入口在详情页；列表角标留待后续 |
| compose 栈 | 整体在 1.13.0-alpha01 + material3 1.5.0-alpha28 | 换取 ButtonGroup / FloatingToolbar / LoadingIndicator 等 Expressive 组件，静态检查与 618 单测已证明现有代码不受影响 |
